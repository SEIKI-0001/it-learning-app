# 学ぶページのテーマ内展開 設計

## 目的

`/learn` でテーマを選ぶ際にページ遷移を発生させず、同じページ内でセクションごとのレッスン一覧を確認できるようにする。学習者が章の構成と次に学ぶレッスンを素早く見比べられる状態にする。

## 対象範囲

- `/learn` のテーマ一覧を対象にする。
- テーマを押すと、そのテーマのセクション見出しと各レッスンへのリンクを直下に展開する。
- レッスンリンクは既存の `/learn/[themeSlug]/[sectionSlug]/[lessonId]` を維持する。
- 「すべて開く」「すべて閉じる」で、現在のフィルター・検索結果に表示されているテーマを一括操作できるようにする。
- 既存の `/learn/[themeSlug]` はブックマーク互換のため残す。

## UI設計

- 各テーマは、章番号・タイトル・進捗・次のレッスンを含む既存の一覧情報を保ったまま、クリック可能な展開ヘッダーにする。
- 展開中のテーマでは、セクションごとにタイトルと説明を表示し、その直下にレッスン一覧を表示する。
- 各レッスンには現在の進捗状態、所要時間、レッスンページへのリンクを表示する。
- 個別テーマの操作には展開状態を表すアイコンと `aria-expanded` を付与する。
- 一括操作ボタンはフィルター・検索欄の近くに置く。表示テーマに展開中のものがあれば「すべて閉じる」、なければ「すべて開く」を表示する。
- 検索または分野フィルターの変更後も、テーマごとの展開状態は保持する。一括操作の対象だけが現在表示中のテーマに限定される。

## 実装方針

- `LearnHome` で展開中テーマIDの集合を状態として保持する。
- テーマ表示を専用コンポーネントへ分割し、既存のテーマカード情報とテーマ詳細ページのセクション・レッスン表示ロジックを再利用する。
- `/learn/[themeSlug]` のルートと `ThemeDetail` は今回の変更対象外とし、既存URLの表示を維持する。
- 新しいクライアント側の状態は、既存のクライアントコンポーネントである `LearnHome` 内に閉じる。

## テスト方針

- テーマ見出しをクリックすると、対応するセクションとレッスンが `/learn` 内に表示されることを確認する。
- 同じ操作でテーマを閉じられること、アクセシブルな展開状態が更新されることを確認する。
- 「すべて開く」「すべて閉じる」が表示中テーマだけに作用することを確認する。
- 既存の全テスト、型チェック、Lint、Next.jsビルドを実行する。

## 受け入れ条件

- テーマの確認時に `/learn/[themeSlug]` へ遷移しない。
- テーマの下で、セクションとレッスン一覧を見られる。
- レッスンを選ぶと、現在のレッスンページを開ける。
- 表示中テーマを一括で開閉できる。
