# Xプロフィール整備デザイン

## 目的

Xアカウントを初めて見た人が、ITパスポート学習支援サービスであることと、提供価値、アクセス先を短時間で理解できる状態にする。通常訴求を主軸にして、期限後も自己紹介を変更せず使える構成とする。

## プロフィール

- 表示名: `ITパスポート学習コーチ｜もちっと`
- 自己紹介: `参考書で止まった人へ。ITパスポートを「さわって理解」する学習アプリ。69トピック＋公式過去問＋毎日の学習計画で、次にやることを明確にします。7日間無料。`
- Webサイト: `https://it-learning-app.vercel.app/campaign/august-2026`
- 所在地: `ITパスポート試験対策`
- ヘッダー画像: 現状を維持する

## プロフィール画像

既存の公式キャラクター「もちっと」の笑顔版を使用する。

- 元画像: `public/characters/mochit/happy.webp`
- 画像サイズ: 512 × 512 px
- 透過背景を維持する
- キャラクターの形、色、表情を変更しない
- Xの円形クロップ内で顔と胴体が判別できることを確認してから保存する

## 運用方針

- 自己紹介では価格や終了日を強調せず、通常のサービス価値を伝える。
- キャンペーン期間中はWebサイト欄からキャンペーンページへ誘導する。
- 期限後はWebサイト欄だけを通常のランディングページへ切り替えられる構成にする。
- 合格保証、架空の実績、利用者数、残り枠は記載しない。

## 完了条件

1. 表示名、自己紹介、Webサイト、所在地が上記の文字列と一致する。
2. プロフィール画像が笑顔版「もちっと」になっている。
3. プロフィール公開画面で文字の欠落や不自然な画像クロップがない。
4. Webサイトリンクがキャンペーンページを開く。
5. ヘッダー画像は変更されていない。
