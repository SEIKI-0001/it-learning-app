# 2026年8月 購入導線改善・全媒体展開設計

## 目的

2026年8月10日23時59分（日本時間）までに、ITパスポート学習コーチ Pro 6か月プランの外部購入を増やす。価格、商品、返金条件、先着特典は既存キャンペーン設計を変更せず、購入導線の見つけやすさと、X以外の高意図流入を改善する。

本設計は、次の承認済み方針を具体化する。

- 購入CTAを明確なボタンとして表示する。
- モバイルのファーストビュー付近から購入カードへ移動できるようにする。
- キャンペーン経由のログインでは、購入ページへ戻れるGoogleログインを主導線にする。
- Instagram、YouTube、note、LinkedInへ同じ価値提案を展開する。

## 変更しないもの

- 商品: ITパスポート学習コーチ Pro 6か月
- 価格: 3,480円（税込・買い切り）
- 自動更新: なし
- 期限: 2026年8月10日23時59分（日本時間）
- 特典: 先着6件を基本とする20分相談1回と相談後のLINEフォロー1回
- 返金条件: 購入日を含む7日以内、かつ20分相談の実施前
- Stripe商品、Price ID、Checkout、Webhook、Pro権限付与
- 合格保証を行わず、購入数や残り枠を捏造しない運用

## 検討した方法

### 1. 既存購入カードの見た目だけを直す

変更量は最小だが、モバイルでは購入カードが長い説明の後にあり、ファーストビューから購入方法を見つけにくい問題が残る。

### 2. ページ上部と下部に購入コンポーネントを二重配置する

購入操作は早くなるが、同じ `id`、決済中状態、エラー表示、権限反映状態が二重になり、利用者と実装の双方で混乱しやすい。

### 3. 既存購入カードを一つに保ち、上部に移動用CTAを置く

採用案。Checkoutロジックと状態表示は一か所に保ち、モバイル上部のCTAは `#purchase` へ移動するだけにする。変更範囲を抑えながら、購入方法の発見性を改善できる。

## 購入ページ設計

### 購入ボタン

`August2026Checkout` 内の未ログインリンク、有効な購入ボタン、準備中ボタンへ共通の視覚ルールを適用する。

- 幅いっぱい
- 高さ44px以上
- ブランド色の背景、白文字、太字
- hover、focus-visible、active状態を表示
- disabled状態は色とカーソルで区別
- リンクとボタンで同じ見た目を使う
- 文言、価格、Checkout処理は変更しない

スタイルはコンポーネント内の共有定数にまとめ、状態ごとの分岐でクラスがずれないようにする。

### モバイル上部CTA

キャンペーンページのヒーロー説明直後に、`lg` 未満でだけ表示されるリンクを追加する。

- 文言: `購入内容を確認する`
- 遷移先: `#purchase`
- 44px以上のタップ領域
- デスクトップでは既存の右側sticky購入カードを使うため非表示
- Checkoutコンポーネントは複製しない

ページ内移動後は、価格、買い切り、自動更新なし、返金条件、ログインまたは購入ボタンを同じカード内で確認できる。

## ログイン導線設計

`/login?next=/campaign/august-2026` の場合をキャンペーン継続ログインとして扱う。

- ページ上部に `ログイン後、購入ページへ戻ります` と表示する。
- Googleログインは既存の `next` を保持する主導線として最初に表示する。
- Googleが利用可能な場合、LINEリンクは白背景の補助導線へ弱める。
- LINEは購入後の相談受け取りにも使えることを短く説明する。
- Googleが未設定の場合は、利用可能な唯一の開始方法としてLINEの現行強調表示を維持する。
- 通常の `/login` では現在のLINE推奨導線を維持する。
- `next` のアプリ内パス検証とオープンリダイレクト防止は変更しない。

LINEリンク自体に戻り先を付与する新しい認証方式は、本キャンペーン期限内の変更対象にしない。

## 全媒体展開設計

### 共通メッセージ

全媒体で次の事実だけを使用する。

- 参考書で止まった人向けに、試験日から逆算して今日やることを整理する。
- 短い問題、解説、AI採点で理解を確認できる。
- Pro 6か月は3,480円、買い切り、自動更新なし。
- 8月10日まで、先着購入者へ20分の学習計画相談がある。
- 合格を保証しない。
- 返金条件と詳細はキャンペーンページで確認できる。

媒体ごとに別の成果や体験談を作らず、既存アプリ画面と公開されている機能を証拠として使う。

### 共通縦動画

Instagram ReelsとYouTube Shortsで同じ20〜30秒の9:16動画を使う。既存のもちっとアイコンと実際のアプリ画面を使い、3場面で構成する。

1. `参考書を開いても、次に何をやるか迷う`
2. `試験日から逆算して、今日の1問を決める`
3. `Pro 6か月 3,480円・買い切り／8月10日まで`

音声がなくても伝わる字幕を入れる。未確認の合格実績、利用者数、残り枠は表示しない。Instagram Storiesでは同じ素材を再利用し、リンクスタンプでキャンペーンページへ案内する。リンクスタンプを自動操作できない場合だけ、最後のスタンプ配置をユーザーに依頼する。

### note

800〜1,200字の無料記事を1本公開する。題名は `ITパスポート勉強を再開するための15分学習プラン` とし、本文の中心は無料で実行できる手順にする。

1. 試験日までの日数を確認する。
2. 苦手を用語、読み違い、計算に分ける。
3. 今日の15分で1問解き、迷った理由を一行残す。
4. 翌日に見直す問題を一つ予約する。

記事中盤と末尾の最大2か所にキャンペーンページへのリンクを置き、販売記事であることを明確にする。

### LinkedIn

働きながら資格学習を再開する人向けに、300〜500字の公開投稿を1件出す。15分学習の実用的な要点を先に示し、末尾で商品、価格、期限、買い切り、自動更新なしを案内する。キャンペーンページへのリンクを1件付ける。

### 公開順

1. note記事を公開し、詳しい説明の受け皿を作る。
2. LinkedIn投稿を公開する。
3. 共通縦動画をYouTube Shortsへ公開する。
4. 同じ動画をInstagram ReelsとStoriesへ公開する。

各媒体でログインが必要な場合は、その媒体のログイン画面で止め、認証情報を読み取らず、ユーザーのログイン完了後に再開する。

## 計測と運用

- 公開URL、公開日時、媒体、内容を既存キャンペーンログへ記録する。
- Xの個別返信上限10件は維持し、全媒体展開を理由に追加返信しない。
- コメントや質問には内容に即した回答を行い、無差別DMを送らない。
- Stripe本番Checkout Sessionの `metadata.campaign=august_2026` で購入を確認する。
- 売上0件の間も購入数や残り枠を推測して表示しない。

## テスト

実装はテストファーストで行う。

- 未ログイン購入リンクが共通CTAスタイルと44px以上の高さを持つ。
- 有効、busy、準備中の各購入ボタンが共通CTAスタイルを維持する。
- キャンペーンページにモバイル用 `購入内容を確認する` リンクがあり、`#purchase` を指す。
- モバイル用リンクがデスクトップ非表示クラスを持つ。
- キャンペーン継続ログインで案内文とGoogle主導線を表示する。
- Googleが有効なキャンペーン継続ログインではLINEが補助スタイルになる。
- 通常ログインとGoogle未設定時のLINE主導線は後退しない。
- 不正な `next` は引き続き `/` に正規化される。

検証コマンドは、対象テスト、`npm test`、`npm run typecheck`、`npm run lint`、`npm run build` とする。本番ではキャンペーンページが200を返し、CTA、ログイン戻り先、3,480円のStripe Checkout表示まで確認する。自己購入は行わない。
