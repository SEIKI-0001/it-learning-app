> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xアカウントを、通常のサービス価値、公式キャラクター、キャンペーン導線が初見で伝わるプロフィールへ更新する。

**Architecture:** 既存の公式キャラクター画像をそのまま利用し、Xのプロフィール編集画面だけを変更する。保存後は公開プロフィールを読み直し、文字列、円形クロップ、リンク先を検証してから運用ログへ記録する。

**Tech Stack:** X Web UI、Codex in-app Browser、既存WebPアセット、Markdown運用ログ

## Global Constraints

- 表示名は `ITパスポート学習コーチ｜もちっと` とする。
- 自己紹介は `参考書で止まった人へ。ITパスポートを「さわって理解」する学習アプリ。69トピック＋公式過去問＋毎日の学習計画で、次にやることを明確にします。7日間無料。` とする。
- Webサイトは `https://it-learning-app.vercel.app/campaign/august-2026` とする。
- 所在地は `ITパスポート試験対策` とする。
- プロフィール画像は `public/characters/mochit/happy.webp` を使用し、キャラクターを加工しない。
- ヘッダー画像、ユーザー名、投稿、返信、フォロー状態を変更しない。
- 合格保証、架空の実績、利用者数、残り枠を追加しない。
