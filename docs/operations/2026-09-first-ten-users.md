# ANDとORが覚えにくいなら、まずスイッチを触ってみる

※私が運営するITパスポート学習アプリ「資格もちっと」の教材を紹介します。

ITパスポートの論理演算で、ANDとORの真理値表を丸暗記しようとしていませんか。まずは「0＝スイッチがオフ、1＝オン」と考えて、ランプが点く条件を試してみてください。

ANDは、AとBがどちらも1のときだけ、出力が1になります。たとえば「宿題も掃除も終わったらゲームをする」の「も」に近い考え方です。どちらかが0なら、出力は0です。

ORは、少なくともどちらかが1なら出力が1です。「電車かバス、どちらかが使えれば出発する」と考えるとイメージしやすいかもしれません。両方が1のときも出力は1になります。

試す順番は3つだけです。

1. ANDを選び、AとBを両方1にする。ランプが点きます。
2. Aだけ0に戻す。ANDではランプが消えます。
3. 同じ入力のままORに切り替える。Bが1なのでランプが点きます。

「入力は同じなのに、ルールが違うと結果が変わる」。これを見てから真理値表を読むと、表の0と1が何を意味しているかを確かめられます。

実際の教材をここで試せます。登録不要・無料で、スマホのブラウザから動きます。
https://shikaku-mochit.com/lp/try?utm_source=note&utm_medium=article&utm_campaign=first_ten

教材にはXORとNOTもあります。XORは「片方だけ1」のときに点灯します。ORと違い、両方が1なら消える点を比べてみてください。NOTは入力を反転します。

資格もちっとでは、SQLやネットワークなどの教材と公式過去問も無料で使えます。続けて学びたい方は、体験ページからGoogleまたはLINEで無料登録できます。クレジットカードは不要です。学習記録の保存は登録後7日間無料で、それ以降も教材と公式過去問は無料で利用できます。料金と保存機能の条件は紹介ページに記載しています。
