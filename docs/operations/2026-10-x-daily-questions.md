# X「毎日1問」投稿原稿（30日分）

公式過去問のうち図表なし・1投稿に収まる問題から、論点が重ならないように30問を選んだ。
問題文と選択肢はIPA公開問題の原文。出典表記は本文の見出しに入れてある（IPAの利用条件）。

## 投稿の仕方

1. 本文を公式アカウント `@itpassportsup` から投稿する。リンクは本文に入れない（Xはリンク付き投稿の表示を絞る傾向があるため）。
2. 1〜3時間後、自分の投稿へのリプとして「リプ」の文面を投稿する。リンクの utm で登録元を追える。
3. 投稿時刻は通学・通勤と昼休みに合わせ、7:30か12:10を目安に固定する。
4. 反応（表示・いいね・リンククリック）を末尾の台帳に1行ずつ記録する。

生成元: `lib/publicPages/kakomon.ts` の公開過去問データ。文字数はXの重み付き（全角2・半角1）で280以内を確認済み。
