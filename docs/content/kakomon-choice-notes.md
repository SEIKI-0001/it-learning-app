# 公開過去問の「選択肢ごとの解説」の書き方

対象: `data/kakomon/choiceNotes/<西暦>.json`（公開過去問ページ `/kakomon/<年度>/<問>` に表示）。
2026-11 の品質改善の試行で決めた書き方。令和7年度（2025）から適用し、令和8年度（2026）は書き直しが終わりしだい同じ形にそろえる。

## ページでの出し方

- 問題データの**段落の解説は必ず残す**。選択肢ごとの解説は、その下に併記する補足であり、段落の解説の代わりにはしない。
- 組合せ問題（記述 a〜d から選ぶ形）は、選択肢（ア〜エ）ではなく**記述ごと**に書く（`statements`）。それ以外は選択肢ごと（`choices`）。

## 1項目の書き方

- 選択肢（記述）ごとに「**なぜ正しいか／なぜ誤りか**」を書く。
  - 誤りの選択肢: その選択肢が本当は何の説明か（用語の正しい意味）と、設問の条件とどこが合わないか。
  - 正解の選択肢: 言い換えではなく、正しいと言える根拠。
  - 混同しやすい用語や選択肢があれば、その違いも書く。
  - 計算問題は、途中の式や数値の動きを書く。
- 目安は **1項目60〜120字**（リンクの記法を除いた文字数。テストで確かめる）。
- 書かないもの: 「これは誤りです」「正しいです」だけで終わる文、「よく出題されます」「覚えておきましょう」のような中身のない文。
- 1問ずつ問題文・選択肢・正解と照らして書く。決まった型に語を差し込むだけの文にしない。
- **内容に自信がない問題は推測で書かない。** 書かずに一覧にして、確認してから書く。

## リンク

関連する英略語・教材のページがあれば、本文の中でリンクできる。

```json
"C": "ISO/IEC 27017は、[ISMS](/words/isms)の規格ISO/IEC 27001・27002を土台に…"
```

- 書けるのは `[表示する語](/words/<id>)` と `[表示する語](/kaisetsu/<topicId>)` だけ。リンク先が存在するかはテストで確かめる。
- その問題の主題の教材ページ（ページ下部に必ずリンクがある）には、本文から重ねてリンクしなくてよい。
- 1項目につき1つまでを目安にする。リンクを張るために文を足さない。

## 正解のチェック

```sh
node scripts/kakomon/check-official-answers.mjs 2025            # IPA の解答PDFを取得して照合
node scripts/kakomon/check-official-answers.mjs --pdf-dir <dir>  # 手元に保存したPDFで照合
```

データ上の正解（表示用・原文・取り込み元の3か所）が、IPA 公式の解答と一致するかを確かめる。
